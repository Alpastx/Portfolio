#### MITRE CVEs

**CVE-2026-89036 — Appwrite argument injection (High)**

- Finder: Alpesh Bhagwatkar (sole credit)
- Assigner: VulnCheck
- Published: 17 Sep 2026 (reserved 10 Sep 2026; `datePublic` 28 Jul 2026)
- Product: Appwrite before 2.0.0
- Class: CWE-88 argument injection
- Scores: CVSS 3.1 8.8 High; CVSS 4.0 8.7 High
- Public summary: authenticated users with `functions.write` or `sites.write` could inject TAB characters into `providerRootDirectory`, which was passed into GNU tar after `escapeshellcmd` instead of `escapeshellarg`. That could inject tar arguments and run code as the builds worker.
- Fix: Appwrite 2.0.0; patch PR [appwrite/appwrite#13028](https://github.com/appwrite/appwrite/pull/13028)

**CVE-2026-86089 — Apache NiFi missing authorization (Low)**

- Finders: ZsZsec and Alpesh Bhagwatkar
- Assigner: Apache
- Reported: 5 Aug 2026; published 16 Sep 2026
- Product: Apache NiFi 2.11.0 (`nifi-web-api`)
- Class: CWE-862 missing authorization
- Score: CVSS 4.0 2.3 Low
- Public summary: REST methods for migrating a version-controlled Process Group into a Connector authorized only against the target Connector. An authenticated user with Connector read could enumerate Process Groups outside their policies. With Connector write they could migrate a Process Group they could not write, copying flow definition, assets, and component state (not sensitive properties). Mitigated in 2.12.0.
- Advisory: [oss-security 2026-09-16](https://www.openwall.com/lists/oss-security/2026/09/16/10)

GitHub shows a personal clone of `appwrite/appwrite` created 15 Aug 2026, which lines up with that research window.
